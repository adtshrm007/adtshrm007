### UpSkillr — Real-time Tech Learning Ecosystem

> A peer-to-peer platform for live mentorship, AI-curated learning paths, and skill exchange.

| Layer | Stack |
|---|---|
| **Collaboration** | WebRTC (P2P video/audio), Socket.io, Operational Transformation |
| **Intelligence** | Adaptive learning paths, AI recommendations, skill gap analysis |
| **Marketplace** | P2P transactions, mentorship matching, rating engine |
| **Infrastructure** | Docker, Kubernetes, horizontal scaling, CDN, DB sharding |
| **Messaging** | RabbitMQ, event-driven microservices |

**Highlights:** Live video sessions · Global CDN · Horizontal scaling · AI-personalized curriculum
